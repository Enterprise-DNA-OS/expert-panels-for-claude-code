# Why this is a database and commands

A panel secretary spends the week finding missing expertise, checking declarations, confirming appointments, renewing terms and preparing a committee brief. Those jobs need joined records and explicit decisions. Commands handle them and read-only HTML shows the result.

This base has no expert portal, mobile application, offline sync, drag-and-drop team builder, survey collection, email delivery, electronic signature or identity provider. It does not replace those Lineup services automatically. Ask Enterprise DNA to scope and test the screens, connections and access your organisation needs before changing service.

All decisions use the CLI. `npm run view` and `npm run docs` create private local files with your business name and colours in brand.json. They are reports, with no action buttons. /new-view adds another report through reviewed SQL. /customise changes the underlying rules through a tested migration.
